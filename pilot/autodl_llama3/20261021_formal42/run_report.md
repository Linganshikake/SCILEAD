# SCILEAD Llama-3 70B：42篇正式子集实验

本轮执行 A/B/C/D/E；没有运行 Cold Start、threshold=2、Llama-2 或付费API。
取得42/42篇原始生成响应（41篇EOS结束、1篇达到长度预算）；格式有效 40/42 篇，实际有效输入 Gold 覆盖 244/259。固定分母评价42篇/259条Gold。超长论文另列 BLOCKED，不能称为完整43篇复现。

## 设置与流程

冻结证据 → 官方 Llama-3 Zero-shot / RetrievalQA stuff → 经批准的格式规则v1 → Fully LLM / CS / Partially两阶段 → 未修改官方评价。
模型 revision：50fd307e57011801c7833c87efa1984ddf2db42f；A80080GB；作者4-bit FP4，模型bfloat16，量化计算float32；greedy、seed0。Extraction预算1024；标准化15；Partially Stage2 100。保持原始EOS与模板，不套用GPT无上限配置。
标准化候选由完整43篇Gold构造23/71/26名称；Partially掩码仍用完整27榜、seed0。Gold对应答案不进入抽取输入。
生成失败或格式失败保持原样；只在独立evaluation_input_fixed42.json中记空预测以固定分母。

## 运行记录
新增本地模型生成 1249 次；复用4次已有抽取；付费API为0次。新增输入 550,141 Tokens，输出 19,426 Tokens。
本轮Extraction墙钟 52.2 分钟；CS 50.7 秒；CS+Partially两阶段共 17.8 分钟。模型加载时间包含在各阶段墙钟中；详细纯生成时间和峰值显存见 generation_usage.json。
短标准化响应仍按官方 `[2:]` 处理。Fully LLM拒绝不在候选集合中的答案并保留null；Partially按原版条件接受已有名称、动态新增名称或拒绝。Fully有1次、Partially Stage1有4次响应达到15 Tokens预算，真实响应保留，没有扩限或重试。

远程正式启动至完成离线重放共 81.63 分钟；其中Fully LLM墙钟 11.32 分钟，新增纯生成累计 43.51 分钟。记录的最大GPU allocated峰值约 49.23 GiB（含复用诊断生成）；它不等于驱动层整卡占用。结束检查GPU已释放至0 MiB，服务器未关机；AutoDL租用费用未核算。

## 格式定位与协议

42篇底层pipeline原始返回均核对为“请求Prompt + 作者包装后的响应”，没有重复拼接Prompt或错误套用chat template。说明性前缀来自模型自身生成。官方README允许在标准化前纠正格式，但未定义具体算法；本轮规则v1经过用户明确批准，属于需要披露的格式协议。官方标准化本身将Result转为字符串，适配层不提前改写数值。
40篇有效输出中，23篇移除了批准的外层包装；数组内部逐字符不变。`2105.03654.pdf` 的1024 Tokens响应截断；`1901.10430.pdf` 虽正常EOS却返回三个独立数组，均未补全、拼接或重新生成。

## 结果解读与辅助诊断

Fully LLM与CS复用同一份271条Extraction，是本轮可直接配对的标准化对照：TDMR F1分别27.25%与24.64%。同范围冻结GPT Fully LLM为43.16%；其Result IIM F1为72.06%，本轮为42.34%。但本轮TDM F1为65.86%，高于GPT的61.83%，说明名称三元组匹配与正确数值及其绑定需要分开评估；不能将整体差距归结为名称标准化。
Partially Stage1的470次名称调用接受已有候选412次，新增10个Task和13个Dataset，其余35次为null。Stage2共175次模型调用，其中86条TDM发生改变，全部Result保持原值；TDMR F1由10.12%到22.04%。这是原版流程两个阶段的观察，不用于选择性报告较高分。
额外严格数值检查：Result IIM F1为25.99%；Fully LLM、CS、Partially Stage1、Stage2的严格一对一TDMR F1分别14.45%、11.77%、4.64%、11.28%。该辅助检查要求整个字符串可解析为Decimal，不接受百分号或“均值±波动”等表达，故不能把全部差额视为错误中心值。
`1511.08308.pdf` 保留重复预测后，官方脚本对部分设置给出TDMR Recall=1.5；未剪裁或改写该官方结果。额外一对一严格评价用于揭示重复计数影响，不能替代官方分数。
具体证据核对：`2020.findings-emnlp.378.pdf` 的正确最佳值已在Table 5，但抽取混入Table 2变体并发生跨列绑定；`D18-1279.pdf` 选择了比较基线值，并将Spanish列数值绑定到CoNLL-2003。这些错误在Extraction发生，标准化名称无法修复；扁平表格可能增加难度，但没有额外解析对照，不能认定其为唯一原因。完整页码和数值见 [人工案例核对](inspection/manual_cases.md)。

## 可比性与边界

同42篇GPT参考见 comparison_with_gpt41.md。GPT为固定快照但不设客户端输出上限，Llama保持作者预算；提示模板也按各自官方模型分支。不是控制所有生成参数的纯模型因果比较。
GPT Partially是历史43篇动态流程输出的42篇筛选；本轮只在可解析的42篇子集输入上动态更新，更新历史不完全相同。
原论文为43篇295Gold与27榜140条，不能将本轮分数直接相减称为全量复现差距。原文与本地硬件、冻结PDF证据、依赖兼容版本和格式协议等差异均需披露，未经对照实验不作单因素归因。
