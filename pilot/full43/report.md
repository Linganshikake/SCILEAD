## 错误归类与严格数值诊断

以下按 Gold 行归类，互斥分类仅定位症状，不自动证明具体错误发生阶段。

| 类型 | Gold 行数 |
|---|---:|
| 数值命中，但对应预测存在标准化 null | 64 |
| 数值未严格命中（含遗漏、差异及非纯数字格式） | 145 |
| 严格完整 TDMR 命中 | 78 |
| 数值命中，但名称或字段绑定不符 | 8 |

标准化 null 字段数：{'Dataset': 45, 'Metric': 65, 'Task': 12}。官方字符串包含与严格 Decimal 比较有 27 对结果不一致。严格 Result 辅助 Macro P/R/F1=0.563627/0.578247/0.570843。这不是官方指标。

严格比较将有限十进制数规范化为数值；每个不同的非纯数字 Result 字符串保留在分母中且不视为匹配，不拆分 ±、单位或多个指标。逐条原始输出、标准化输出、Gold、候选匹配索引见 `evaluation/tdmr_comparison.md`。

Baseline 混入、Dev/Test 混淆及表格标题错配只记录已有证据支持的例子，未逐项人工裁决的情况不编造总数。详细说明见 `inspection/findings.md` 与 `inspection/manual_findings.md`。
