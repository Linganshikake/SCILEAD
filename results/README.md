## 阅读规则

- P/R沿用官方逐篇Macro；F1=2PR/(P+R)，不是逐篇F1均值。下表数值为0–1。
- IIM的T/D/M/R分别是Task、Dataset、Metric、Result。官方Result允许字符串包含匹配；严格数值辅助指标在各实验目录，不能混用。
- 不同范围（43/295、42/259、37/248）、模型Prompt与生成预算存在差异；本表是结果索引，不是控制所有变量的公平排名。
- PC/RC/数值列表RBO沿用官方实现；LR、非空率和论文ID AO是已记录定义的补充统计。RBO不等于AO。
- GPT-4.1实际模型固定gpt-4.1-2025-04-14；Llama-3为原本地70B及其标准化流程；AxCell抽取仍为原AxCell。
