SCILEAD 实验复现项目——迁移记忆

一、项目基本信息

目标论文： Efficient Performance Tracking: Leveraging Large Language Models for Automated Construction of Scientific Leaderboards

作者：Furkan Şahinuç, Thy Thy Tran, Yulia Grishina, Yufang Hou, Bei Chen, Iryna Gurevych。 EMNLP 2024，论文页码 7963–7977。

论文核心任务是从科学论文中自动抽取 <Task, Dataset, Metric, Result> (TDMR) 四元组，并进一步利用这些信息构建、更新 Scientific Leaderboards。 论文提出三种主要实验设置： Fully Pre-defined、Partially Pre-defined、Cold Start。

本项目的核心目标不是改进 SciLead，而是： 尽可能严格复现原论文实验，再对复现实验与原论文结果进行系统比较。

五、Fully + CS 标准化实验

目录： 

D:\C++\SCILEAD\pilot\full43_cs

使用： Lajavaness/bilingual-embedding-large， CPU FP32。

这一实验不重新 Extraction，而是对相同的原始 Extraction 结果，将 LLM Normalization 替换为原论文 CS / cosine similarity normalization。

指标 LLM Normalization F1 CS Normalization F1
Task IIM0.9669000.972757
Dataset IIM0.8007140.877961
Metric IIM0.8532240.858958
Result IIM0.7038410.703841
TDM0.6121600.713128
TDMR0.4215780.542610

最重要发现： 在完全相同的 Extraction 结果下，仅替换 Normalization 方法，TDMR F1 从 42.16% 提升到 54.26%，提高 12.10 个百分点。

这说明： Normalization 是当前系统性能的重要瓶颈，尤其是 Dataset normalization。

但 CS 并非全部正确。例如：

  • WN16 / WN17 → WNUT-16 / WNUT-17：正确
  • ON5E → BC5CDR：错误
  • RE → RTE：错误
  • ROUGE-L → BLEU：错误
  • GLUE → SNIPS：错误

因此“候选集合内”不等于“语义正确”。

十五、实验过程中的重要发现

1. Dataset Normalization 是关键瓶颈

Fully LLM： Dataset IIM F1 = 80.07%

CS： Dataset IIM F1 = 87.80%

Few-shot： Dataset IIM F1 = 88.70%

说明 Dataset normalization 对最终 TDMR 有非常直接的影响。

2. Normalization 对 TDMR 的影响非常大

相同 Extraction：

LLM normalization： 42.16%

CS normalization： 54.26%

提升： +12.10 个百分点。

3. Few-shot 的作用不是简单“越多越好”

Zero-shot： 42.16%

Few-shot Extraction + Zero-shot Normalization： 33.12%

Few-shot Extraction + Few-shot Normalization： 55.73%

说明 Few-shot 对两个阶段存在明显交互作用。

4. Cold Start 对输入顺序敏感

三轮 Cold Start 的 LR： 39.51% ± 8.55%。

说明 Cold Start 中模型生成候选知识集合时存在明显的顺序效应。

5. Result Extraction 是最难的局部任务之一

Baseline Result IIM F1： 70.38%。

虽然明显低于 Task，但真正困难之处还包括：

  • 正确表格定位
  • 方法变体判断
  • Dev/Test 区分
  • Baseline / Proposed Method 区分
  • 多个指标绑定
  • 复合数值拆分

6. 数值正确不代表 TDMR 正确

存在大量“数值已经正确，但 Dataset/Task/Metric 错误”的样本。

因此后续分析不能只看 Result IIM，而必须联合： IIM → TDM → TDMR → Leaderboard-level。
